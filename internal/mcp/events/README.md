# Experimental MCP Events

This package implements the **draft** [MCP Events design sketch](https://github.com/modelcontextprotocol/experimental-ext-triggers-events/blob/main/docs/design-sketch-proposal.md), independently of the core MCP protocol's `subscriptions/listen` notification stream. It exposes `events/list`, `events/poll`, `events/stream`, `events/subscribe` and `events/unsubscribe`.

Only four built-in event types are provided: `mcp.tools.list_changed`, `mcp.resources.list_changed`, `mcp.prompts.list_changed`, and `mcp.resources.updated`. They wrap actual changes from authorized upstream MCP services. This package does not invent email, payment, GitHub, or other business events. Such events need an actual upstream source and a separately designed catalog/schema.

The gateway supplies a scoped `Source` and a `Principal.Check` callback. Checks run on requests and before delivering each cached event, including every webhook retry. `EventFromContext` exposes that event to the check so removing a service from a group or disabling a resource also revokes historical delivery. The transport supplies `params._meta["io.modelcontextprotocol/subscriptionId"]` and the final stream JSON-RPC response, because this package does not receive request IDs.

A source supervisor reports later disconnections or scope failures with `FailSource(sourceContext, err)`. The manager ends delivery with a typed error and cancels the source. Teardown runs outside locks on a managed worker so a supervisor can report its own failure without waiting on itself. An unrelated or already stopped context safely returns false.

Poll listeners have renewable five-minute leases. Push listeners end with their request. Webhook subscriptions grant at most five minutes, including a `ttlMs: null` suggestion; the minimum finite grant is one second. They are memory-only soft state: process restarts lose listeners, callbacks, verification and replay history. Clients refresh before `refreshBefore`, save returned cursors and use `truncated` to detect a gap. There is no durable or exactly-once delivery promise.

Replay buffers are bounded by five-minute retention, 256 events and 1 MiB per feed, with a 16 MiB aggregate payload cap. Limits also apply to feeds, concurrent streams, webhook subscriptions and callback verification state. Cursor scope includes the authenticated principal, event name and canonical string-valued arguments. A null cursor starts from now; `maxEvents` returns intermediate cursors and `hasMore`; `maxAgeMs` and retention signal `truncated` when events were skipped.

Webhook identity is `(principal, delivery.url, name, arguments)`. Subscribe idempotently refreshes this key; unsubscribe takes `name`, `arguments` and `delivery.url`, never the derived ID. Secrets are client-provided `whsec_` base64 values decoding to 24–64 bytes. Every POST is signed using Standard Webhooks HMAC-SHA256 over the raw body, with a stable event ID across retries and newly generated timestamps/signatures. Rotation dual-signs for 30 seconds. Deliveries are serialized per subscription, with three attempts and bounded request timeouts; HTTP 410 and 413 are not retried. Payload cursors are conservative acknowledged/abandoned watermarks; refresh advances the watermark after accepted deliveries. `deliveryStatus` reports category-only failures; endpoint bodies, credentials and headers are never exposed or logged.

Delivery activates only after a signed `verification` envelope receives a 2xx JSON body echoing its challenge in constant time. Verification caches are scoped by principal and exact URL, with host-rate limits. Production permits only HTTPS globally routable callback addresses, checks **all DNS answers again on every attempt**, pins dialing to checked IPs, retains the hostname for TLS/Host, ignores environment proxies, and never follows redirects. There is no production switch allowing private destinations; package-private hooks support isolated TLS tests. Unsubscribe, expiry, revocation, request cancellation and `Close` cancel workers and release source listeners once no poll lease or other delivery still needs them.
